## 🌟 Why Finance Planner?
Most generic investment apps only tell you what your portfolio is worth today. They don't tell you the most critical thing a **salaried professional** needs to know:

> **"Did my wealth grow this month because the market went up, or did it only grow because I pumped ₹40,000 of my own paycheck into it?"**

Finance Planner is built to answer that exact question. Every month on **Review Day (Payday Ritual)**, it cleanly isolates:
1. **Fresh Salary Injected** (Your savings discipline)
2. **Organic Market Compounding** (Your capital working for you)

## 🔑 Key Features

### 1. Multi-Asset Portfolio Tracking
- **Mutual Funds & Index ETFs**: Real-time NAV search and daily price lookups via the 100% free, open AMFI community API (`api.mfapi.in`).
- **Direct Stocks (NSE / BSE / US)**: Quotes for Indian stocks (`TCS.NS`, `INFY.NS`, `RELIANCE.NS`) and US equities (`AAPL`, `GOOGL`).
- **Fixed Deposits (FD/RD), Bonds, & PPF**: Automatic mathematical compound interest calculation ($A = P(1 + r/n)^{nt}$) with maturity date countdowns. No external API needed.
- **Gold**: Tracks domestic spot gold via `GOLDBEES.NS` (Nippon India Gold ETF) or physical gold grams.
- **Emergency Fund & Liquid Cash**: Live gauge tracking how many months of living expenses you can survive without a paycheck.

### 2. Rich Visualizations & Analytics
- **Wealth Compounding Journey Area Chart**: Clear visual gap showing the "free money" generated by compounding above your invested salary.
- **Asset Allocation Donut**: Interactive category breakdown (Equities, Debt, Gold, Cash).
- **Monthly Growth Waterfall Chart**: Green/Red monthly deltas with instant hover breakdown of salary vs market returns.
- **Underperformer / Dead Capital Detector**: Automatically flags funds trailing standard bank FD interest rates (7.0%).
- **Asset Allocation Drift Advisor**: Highlights when equities or cash drift away from your target risk profile.

### 3. Future Wealth Predictor (6 to 36 Months)
- Dynamic scenario modeling:
  - **Conservative (Worst Case)**: Market correction / flat markets, safe FD return only.
  - **Moderate (Current Pace)**: Weighted historical returns + disciplined monthly savings.
  - **Aggressive (Bull Market)**: Bullish rally + 10% annual salary/SIP increment.
- Interactive "What-If" slider: adjust monthly savings from ₹5,000 to ₹2,50,000 in real-time.

### 4. Gold Price Prediction Agent & Intelligence Engine
- **Autonomous Multi-Factor Forecasting**: Decouples US 10Y Real Yields (TIPS), US Dollar Index (DXY), Brent Crude, Central Bank physical accumulation (PBOC, RBI), COMEX/CFTC speculative positioning, and Indian rupee landed duty dynamics.
- **Probabilistic Forecasting Cones**: 5,000-path Monte Carlo fan charts across 1d, 7d, 30d, 90d, and 180d horizons with Bull/Base/Bear scenarios.
- **Interactive "What-If" Macro Shock Simulator**: 6 real-time sliders (Fed rate, DXY, Real Yields, GPR index, Oil, USD/INR) with immediate price recalibration.
- **India Domestic Landed Pricing Engine**: Decouples international USD spot from Indian retail gold: $((\text{USD Spot} \times \text{USD/INR}) / 31.1035) \times (1 + \text{Customs Duty } 6\%) \times (1 + \text{GST } 3\%) + \text{Domestic Spread}$. Computes 24K, 22K, per-gram metrics, and GOLDBEES fair value.
- **Immutable Continuous Learning Ledger**: Cryptographic prediction ledger with rolling walk-forward backtesting and objective performance benchmarks (MAE, RMSE, MAPE, Directional Hit Rate).

### 5. Smart Excel / CSV Historical Data Importer
- Import 2–3 years of past monthly spreadsheets in seconds.
- **In-Browser SheetJS Parser**: Your spreadsheet is processed 100% locally on your machine—never uploaded to a cloud server.
- **Column Auto-Detection & Mapping**: Easily map your Excel headers to the app's schema.
- **Live 5-Row Preview** before committing.

### 6. Bank-Grade Local Privacy & Security
- Protected by a **Master PIN**.
- All portfolio numbers stored in browser `IndexedDB` are encrypted using **military-grade AES-256-GCM** via the Web Crypto API.
- 1-click **Export Encrypted Backup (.json)** and **Restore** makes migrating to another device or browser effortless.

## 🚀 Getting Started

### Option 1: Zero-Installation (Instant Local Use)
You don't need to install Node.js, Python, or anything else!
1. Simply double-click `index.html` in file explorer or open it in Google Chrome, Microsoft Edge, Brave, or Firefox.
2. The app will load with an optional demo portfolio (including 12 months of historical snapshots) so you can test all charts, sliders, and reviews immediately.

### Option 2: Run with Local Web Server (Python or Node)
If you prefer running through a local web server:

**Using Python:**
```bash
cd c:\work\FinancePlanner
python -m http.server 3000
```
Then open `http://localhost:3000` in your browser.

**Using Node.js / Vite:**
```bash
npm install
npm run dev
```

## 🌐 Free 1-Click Deployment

### Deploying to GitHub Pages (\$0 Forever)
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial Finance Planner commit"
   git branch -M main
   git remote add origin https://github.com/corporatevinoth/FinancePlanner.git
   git push -u origin main
   ```
2. Go to your repository on GitHub:
   - Click **Settings** $\rightarrow$ **Pages** (left sidebar).
   - Under **Build and deployment > Branch**, select `main` and `/ (root)`.
   - Click **Save**.
3. Your app is live at `https://corporatevinoth.github.io/FinancePlanner/`!

### Deploying to Vercel (\$0 Forever)
1. Go to [vercel.com](https://vercel.com) and sign in with GitHub.
2. Click **Add New... > Project**.
3. Select your `FinancePlanner` repository.
4. Keep the default settings and click **Deploy**.
5. Your app is instantly deployed on a global CDN with free SSL HTTPS!
